### Added — attraction_kind accepts MAZE

`ATTRACTION_KIND_VALUES` gains `MAZE`: a scare-actor walk-through that runs only
during a Halloween event. Year-round haunted rides stay `RIDE` or
`WALKTHROUGH`. The column is `text`, so there is no schema change. The admin
`PATCH` (single and bulk), the `GET /v1/admin/content/fields` options and the
Swagger enums read the same list and pick the value up without further edits.
