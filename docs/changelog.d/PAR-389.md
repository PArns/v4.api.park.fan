### Fixed — the build writes `dist/swagger-spec.json` again

The `postbuild` step bootstrapped the whole app, which tried to reach Postgres, and Nest's default `abortOnError: true` ended the process with exit 1 before the script's own catch ran; `logger: false` hid the error and `|| echo` hid the exit code. It now creates the app with `preview: true`, which reads the controller and DTO metadata without connecting to anything, and a failure prints its stack through the existing warning. The OpenAPI config and the `/robots.txt` prefix exclusion moved to `src/common/swagger/swagger-config.ts`, shared with `src/main.ts`, so the build-time spec matches the one the API served at runtime: identical `paths` and `components` against the live `api-json`.
