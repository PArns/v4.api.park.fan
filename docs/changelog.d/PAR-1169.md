### Added — a park's abbreviations, curated, in the park payload

`curated_abbreviations` is a new hand-written park column (comma separated, „EP“ for Europa-Park,
„PHL“ for Phantasialand), in the editor's „Identität“ group. The park payloads (`ParkWithAttractionsDto`,
`ParkResponseDto`) carry it as `abbreviations: string[]` when one is set: split at commas, trimmed, at
most five of up to 12 characters, duplicates in any case and the park's own name dropped
(`resolveAbbreviations`). The editor refuses a value it would not serve as typed: another separator
than the comma, a sixth entry, a longer one, the park's name (`abbreviationsProblem`).
Search Console shows them searched: „ep wartezeiten" 563 impressions, „uss waiting time" 155, „sfga
wait times" 127 in 28 days. See [curation](admin/curation.md).
