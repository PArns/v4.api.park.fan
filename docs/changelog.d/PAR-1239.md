### Fixed — a queue failure a later run already fixed no longer turns red again in the admin

The admin listed "Queue pcn-shadow: Jobs fehlgeschlagen" for a `train-pcn` run that failed on 2026-10-31
(`getaddrinfo EAI_AGAIN pcn-service`, a container restart), although training has completed every day
since. A failure counted as settled only while a later success of the same job was in Bull's
`completed` set, which keeps the last 100 runs of a queue; pcn-shadow's 15-minute forecast and hourly
score push the daily training out of it within a day. Every completed run now also writes its job name
and finish time to `<prefix>:<queue>:last-success` (`QueueSuccessRecorderService`), seeded at start from
what the set still holds, and `newestSuccessByName` reads both. The admin's queue card and the
data-quality report share it.
