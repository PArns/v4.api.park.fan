### Added — Every Parky answer keeps the prompt version it was written with

Until now the admin showed only the prompt version running at the moment, so a stored chat did not
say whether it came before or after a prompt fix. `assistant_messages.promptVersion` now holds
`SYSTEM_PROMPT_VERSION` for each answer, and `assistant_conversations.promptVersion` the version of
the chat's latest answer. The admin's chat list and the MCP tool `assistant_conversations` filter
by it (`promptVersion`), and `assistant_conversation` shows it per answer. Both columns are
nullable: chats stored before them have none. See [Parky](frontend/assistant.md).
