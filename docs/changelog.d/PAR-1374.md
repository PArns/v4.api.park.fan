### Added — a weekly keyword report from Search Console

`GET /v1/admin/search-console/keywords` and the MCP tool `gsc_keywords` compare the last complete
week with the one before for the queries with the most impressions: each keyword's position, clicks
and impressions in both weeks, the places it moved and the page that ranks, and a summary with
visibility, top 3 and top 10, risers, fallers, new and lost keywords.
