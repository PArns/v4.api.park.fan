### Fixed — the live model comparison scores against observed truth, at served precision

The forward archive's truth counted the hourly heartbeat rows, which copy the
last wait with a fresh timestamp: a ride whose feed went quiet kept producing
truth at a frozen value, and persistence scored 0 there (11–13 % of truth slots
in early October). Truth now skips them. Paired slot waits are compared after the
same serve-side rounding (5-minute steps, floor 10) on both arms, so an unrounded
candidate no longer wins by rounding alone. The 14-day gate counts the dates each
park reached instead of the union over parks, and a cell turns `better` only when
the offline verdict agrees with the live one — the owner's offline-AND-live rule.
Paired rows carry the definition they were scored under, and the matrix reads only
the current one. The daily scoring run replays the last 14 dates under the new
definition from the archived curves (5 per run), so the gates start from those
14 dates rather than from zero.
