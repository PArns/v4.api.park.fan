### Added — Chronos-2 and TimesFM 3.0 as ml-bench plug-ins, scored like every other candidate

`ml-bench/mlbench/models/foundation.py` plugs the two time-series foundation models
into the PAR-827 benchmark through the restricted plug-in interface, so they are
paired against the same baselines on the same rows as everything else. Chronos-2
takes a whole park as one multivariate task (every ride a variate, the covariates
shared); TimesFM 3.0 caps variate attention at 32, so each ride is a univariate task.
Both are run on a compressed context of operating-window slots only — nights and
closed days left out, the day boundary carried by the covariates — with the
regular-grid layout and a covariate-free variant as controls, plus an ORACLE-weather
variant reported separately as an upper bound. A daily level path feeds the harness's
`level × H5` composition so d10–d90 and the crowd calendar are scored without asking
for 15-min slots there.

The first scored subset run settles the two design questions: the regular-grid layout
beats the compressed context in all 18 slot-MAE cells (the compressed context buys a
170-day history but destroys the opening ramp, which is what the rope-drop and
best-time decisions score), the covariates are worth 0.39–0.82 min of MAE, and
perfect weather foreknowledge is worth under 0.1 min — so weather is not the missing
ingredient. Against persistence, the reference no profile baseline beats inside two
hours, Chronos-2 loses at 15 minutes and wins from 30 minutes out to 2 hours by
−0.42…−2.27 min on all rides and −0.92…−4.51 on ex-ante busy rides.

The harness gained `--parks` for subset runs that still re-score the baselines on
exactly the same parks, `run --pair-with` / `report --vs` for paired
model-against-model intervals (they have to be requested at run time, because the
per-slot forecasts are not kept), a separate q95 denominator for models whose
quantile head stops at 0.9, and opt-in pre-origin covariates for context models. A
run's git SHA is now written into the image as a file as well as an environment
variable, and the run script refuses to start — and declares a finished run void —
when the SHA cannot be tied to a commit containing the harness fixes the scores
depend on.

Chronos-2 is Apache-2.0; the TimesFM 3.0 weights are non-commercial, which covers
this benchmark but leaves production serving as an owner decision. See
docs/ml/foundation-models.md.
