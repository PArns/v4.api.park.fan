### Added — Chronos-2 and TimesFM 3.0 as ml-bench plug-ins, scored like every other candidate

`ml-bench/mlbench/models/foundation.py` plugs the two time-series foundation
models into the PAR-827 benchmark through the restricted plug-in interface, so
they are paired against the same baselines on the same rows as everything else.
Chronos-2 takes a whole park as one multivariate task (every ride a variate, the
covariates shared); TimesFM 3.0 caps variate attention at 32, so each ride is a
univariate task. Both are run on a compressed context of operating-window slots
only — nights and closed days left out, the day boundary carried by the
covariates — with the regular-grid layout and a covariate-free variant as
controls, plus an ORACLE-weather variant reported separately as an upper bound.
A daily level path feeds the harness's `level × H5` composition so d10–d90 and
the crowd calendar are scored without asking for 15-min slots there. The harness
gained `--parks` for subset runs that still re-score the baselines on exactly the
same parks, a separate q95 denominator for models whose quantile head stops at
0.9, and opt-in pre-origin covariates for context models. Chronos-2 is
Apache-2.0; the TimesFM 3.0 weights are non-commercial, which covers this
benchmark but not a production serving decision. See
docs/ml/foundation-models.md.
