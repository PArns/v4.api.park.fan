### Fixed — an offline win counts only when it was measured against what is served

`offline-model-verdicts.json` now states, per question × model, what the offline
figure was measured against (`reference`), on which metric, from which run, and
the paired difference with its interval — null wherever no bench export has
reported one, which is every entry today: no number was added. A cell turns
`better` only when the offline win is against the question's served model; a
win over persistence or the weekday average reads `pending` with a note saying
so. This takes `live_h1_2` × Chronos-2 (offline better than persistence, PCN is
not in the bench) off the path to `better` on a live win alone. The admin DTO
gains `reference`, `referenceIsServed`, `metric` and `runId` on the offline
block, all optional.
