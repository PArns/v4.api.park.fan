### Added — the attraction detail says whether the ride has a day curve

Every ride page asked `/stats/day?attraction=<slug>`, and the route answers only for the park's
eight day-curve candidates: in a sample, 34 of 454 rides had a curve, so about 92 % of those
requests ended in a 404. The attraction detail now carries `hasDayCurve`, read from the cached
hourly profile the route picks its rides from and never computed for the detail; it is absent
while that cache is cold, which means unknown. park.fan skips the request when it is `false`
([ride day curve](frontend/ride-day-curve.md)).
