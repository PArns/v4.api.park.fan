### Fixed — the calendar counts only a park's own influencing regions as influencing holidays

`influencingHolidays` on a calendar day took every non-local holiday row of the
park's country, so since the curated US school calendars (PAR-1071) a TN or NC
break listed under Disneyland and, from two such rows, added +1 to the day's
recommendation score. The list now keeps only holidays whose region is in the
park's `influencingRegions`, the same rule `neighborHolidays` already used. ML
features are unchanged. See
[holiday sources outside Europe](architecture/holiday-sources-outside-europe.md).
