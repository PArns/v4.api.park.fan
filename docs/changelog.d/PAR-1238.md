### Fixed — the URL inspection cache folds a trailing slash, and the Search Console e2e suite is green again

`gsc_inspect_url` kept a trailing slash, so `/de/parks/x/` and `/de/parks/x` were two cache entries and the
first asked Google about a URL the site only redirects (Next.js serves no trailing slash).
`normalizeInspectionUrl` now drops it, except on the root.

`test/e2e/search-console.e2e-spec.ts` had failed six tests on every branch since late October. Not a date
drift: the spec still expected the behaviour from before three changes it was never updated for. Those
are empty days asked again until ten days old (PAR-1181), the property's totals on the queries report
and the `gsc_queries` tool ([search-console contract](frontend/search-console.md)), and a first import
that backfills all four search types. The expectations now follow the code, and the trailing-slash case
was the one real bug among them.
