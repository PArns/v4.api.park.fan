### Added — Parky reads how any past day went, up to a year back

`get_park_history` knew only the same date a year earlier. "How busy was Europa-Park last
Saturday?" had no tool behind it.

- `get_park_history` takes `on`, a past day it reads itself, up to a year back, by the calendar's
  own history path. As for the year-back days, a level counts only where it was measured.
- The system prompt (version 33) sends a question about a past day there.

When a ride last ran is still missing: it needs a query on `queue_data` that the E2E suite has to
cover (PAR-1267).
