### Fixed — A Search Console day Google delivers late is still imported

A day Google had no final numbers for yet came back empty, was stored as an
empty batch, and was asked about again only while it was among the last three
days. Google's final numbers usually arrive two days late, which left one night
of margin: a delay of a few more days would have left the day empty for good.
An empty day is now asked again until it is ten days old; an answer that is
still empty writes nothing, so the cost is a few requests a night for the types
that are often empty (news, Discover). See
[Search Console](frontend/search-console.md#the-import).
