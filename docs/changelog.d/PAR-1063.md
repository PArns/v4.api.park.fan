### Added — ml-bench: Chronos-2 LoRA plug-in and a one-origin `--probe`

`chronos2_lora` fine-tunes a LoRA adapter on Chronos-2 with chronos-forecasting's own
`fit(finetune_mode="lora")` (peft), on exactly `chronos2_ft`'s inputs, steps, learning
rate and 28-day refit cadence, so the pair isolates full vs low-rank adaptation. Each fit
trains on truth before its own daily origin; a test poisons every later slot and asserts
the fit's inputs do not move. The backend refuses to start without peft, because the
package would otherwise warn and silently run a full fine-tune under the LoRA name.
`mlbench run --probe` runs only the first origin and records wall time, peak GPU memory
and each plug-in's call and fit seconds in `run-*.json`, to size a run before booking the
GPU. Dependencies in the optional `requirements-par1063.txt`; nothing has been run on the
GPU yet — the commands are in `docs/ml/ml-bench/running.md`.
