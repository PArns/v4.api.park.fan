### Fixed — The ML overview sees a failed PCN training, and a new TFT run is served at once

The admin ML overview judged PCN only by its newest forecast, which keeps coming
from the previous model when training fails. It now also reads pcn-service
`GET /train/status` (3 s timeout, ignored when unreachable) and shows `failed`
with the error, as TFT and CatBoost already did. A completed `train-nf` run now
evicts the 13-hour `ml:tft-daily:*` cache (SCAN, not KEYS), so the calendar no
longer serves the previous night's TFT run until that cache expires.
