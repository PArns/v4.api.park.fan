### Added — sights from OpenStreetMap: Efteling's Holle Bolle Gijs bins and named statues

`/facilities` serves a third type, `sight`
([facilities](frontend/facilities.md#the-contract-a-client-reads)): a named
`amenity=waste_basket` (a figure bin, since an ordinary bin has no name) or a named
`tourism=artwork`, inside the park's outline. At Efteling that is the eleven Holle Bolle Gijs
("Opa Gijs", "Kapitein Gijs" …) and four statues, all inside the outline on 2026-11-28. A sight
always has a name and none of the toilet fields; an element that is also a toilet or drinking water
stays that type (the Drinkebroer). Two sights within 15 m are one only when they carry the same
name, so a pair of statues stays two. `tourism=attraction` without a ride tag (the Sprookjesbos
fairy tales) is left out on purpose: in many parks that is also how rides are mapped.

The Overpass query asks for the two new tags with a `name` filter, so the unnamed bins (112 of the 123
around Efteling) never leave Overpass. The admin's park list counts `sights` beside toilets and
drinking water, and the bulk approval's three visible points count every type. Parky's
`find_nearby` takes `sight` as a kind and the `navigate` card `place: "sight"`; the credit names
the layers asked for ("Sights: © OpenStreetMap contributors"), prompt version 70. No schema change:
`type` was already text.

- A re-import no longer takes an approved park offline. New points, and points whose shown fields
  changed, come in as `awaitingReview` (new column on `park_facilities_osm`, default `false`, so
  every existing row stays served) and wait for the next approval; the rest of the park stays
  served. The park still goes back to "Zu prüfen", and `counts.awaitingReview` says how many
  points wait. `approvedAt` is now the last approval and survives that step; withdrawing clears
  it. Before, the 107 approved parks would have gone dark on the first re-import that found a
  sight.
- Web and app show the new type in PAR-1460 and PAR-1461; until then they ignore it, as the
  contract asks of an unknown `type`.
