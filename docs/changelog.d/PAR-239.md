### Added — the attraction merge preview names the review marks the merge deletes

`AttractionMergeService.previewMerge` (and the `droppedCurations` of a batch dry
run) now lists the `attraction_review_marks` rows a merge would delete, with
`kind` and `reason`. A mark about exactly the two rides being merged carries
`aboutThisPair: true`; a `not_a_duplicate` mark there means somebody already
decided the two are different rides. The merge is not blocked; the preview only
reports it.

The preview and the merge read one function, `planAttractionReviewMarks`: the
merge deletes the marks it returns by id, and `MergeDependency.plan` hands the
same answer to the preview. No schema change.
