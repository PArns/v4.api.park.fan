### Added — ml-bench: tabular foundation models as the daily-level learner, and decided arms retired

Two new benchmark arms, `kumo_level` (NVIDIA Kumo-Tabular, weights OpenMDW-1.1) and
`inpriora_level` (Inpriora, weights Apache-2.0). Each is `driver_level` with only the learner of
`log(true P90 / naive)` swapped for an in-context forward pass over a seeded sample of at most
50,000 training rows, so a margin against `driver_level` is the learner alone. They come from the
TabArena leaderboard of 2026-11-21. There, on regression, the best servable model, Kumo-Tabular,
scores Elo 2475 [2298, 2723] against 1518 for tuned and ensembled CatBoost. A model was taken only
if its licence allows serving and its interval overlaps Kumo-Tabular's. That drops Mitra-v2, TabICLv2,
TabDPT and every non-commercial model (LimiX-2, TabPFN-3.5, Lattice, TabFM, Causilo, …). Only the
daily level is in reach, because TabArena's regression datasets have at most ~36k training rows and
BeyondArena sees trees ahead on large or grouped data. Kumo-Tabular passed a CPU smoke with its real
weights; Inpriora's code has no PyPI release and waits for a review of its git dependency. Neither
has been scored on the production export yet; both join the combined run of PAR-1141, built with
`requirements-par1405.txt`. The admin model comparison shows them as the offline-only column
„Kumo-Tabular / Inpriora“ (`tfm`) on the four calendar questions, not measured until then.

Arms whose question is answered are now listed in `RETIRED` (`mlbench/models/__init__.py`), and
`mlbench run` refuses them unless `--allow-retired` is passed: `timesfm3*` (no q95, non-production
weights), `toto2*` (behind Chronos-2), `nf_tide*`, `nf_nhits`, `nf_tsmixerx` (lose to Chronos-2)
and `tabpfn_ts` (benchmark-only weights, so no result could ever be served). Their code and tests
stay. No production shadow was switched off: on 2026-11-21 none had a decided loss, and every
pending decision has its date on the admin ML overview. Details:
[tabular foundation models](ml/foundation-models/tabular.md).
