### Fixed — an empty query integer takes the route's default, not 0

`QueryIntPipe` read `?limit=` and `?radius=` as 0 because `Number("")` is 0, so
the route's default never applied. An empty or blank value now counts as
absent. `?x=0` still parses as 0. The pipe is used by `parks` (page, limit,
days), `location/nearby` (radius, limit) and `ml` (limit, days); none of them
depends on an empty value meaning 0.
