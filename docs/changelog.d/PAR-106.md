### Fixed — a merged park season no longer names rides the merge deleted

`park_seasons.attraction_ids` is a jsonb array with no foreign key. When a merge
collided a ride, the season moved onto the surviving park still naming the deleted
loser, and `ParkSeasonService` then refused every later edit of it with "These
attractions are not in this park".

`remapSeasonAttractionIds` is now a `custom` entry on `ATTRACTION_DEPENDENCIES`, so
`ParkMergeService.mergeParks`, `AttractionMergeService.mergeAttractions` and both
raw paths in `parks.service.ts` rewrite the loser's id to the survivor's. Ids that
resolve to no ride are dropped, duplicates collapse, and an emptied array is stored
as NULL. No schema change.
