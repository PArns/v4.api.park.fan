### Fixed — Feature drift reports "no data" instead of all-healthy

With no production feature values to compare (production writes none:
`prediction_accuracy.features` is empty), `detectFeatureDrift` counted every
feature as healthy — "75/75 healthy" from no data, and the drift alert could
never fire. The summary now carries `status: "no_data"` with all counts 0, the
monitoring job logs it as a warning, and the alert check keeps a low
`feature_drift` alert "Feature Drift: No Data" open instead of resolving it.
