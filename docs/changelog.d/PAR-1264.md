### Added — Parky lists the rides that keep you dry when it rains

Parky knew a ride's `indoorOutdoor` only one ride at a time through `get_ride`. Asked to plan a
rainy day at the Parque de Atracciones de Madrid, he said to start with the indoor rides and named
none.

- `compare_rides` and `show_card` kind `rides` take `shelter`: `covered` keeps the rides an editor
  marked `indoor` or `covered_queue`, as the frontend's „Überdacht" filter does; `indoor` only the
  first (`isSheltered`, `ride-facts.util.ts`).
- Rides nobody decided are counted as `shelterUnknown`, never read as outdoor. Under half of them
  known, the result says `shelterIncomplete`, the frontend's `COVERED_MIN_KNOWN_SHARE`.
- The card's rows carry each ride's `indoorOutdoor`, so Parky can say a roofed queue still leads to
  a ride outside.
- The system prompt (version 30) sends a rain question to this filter.
