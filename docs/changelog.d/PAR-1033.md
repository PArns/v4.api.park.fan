### Fixed — TFT daily panel: partial today, heartbeats, southern seasons; calendar-day grid behind a flag

The TFT training panel no longer includes park-local today, which at the 03:00 UTC
run was a partial morning in Tokyo and Shanghai and became the last context value
and a training target. Heartbeat rows (copies of the last reading) are excluded
from the target, as the forward archive's truth already does (PAR-1039).
`is_peak_season` follows the park's hemisphere. A new `NF_CALENDAR_GRID` flag
(default off) trains on full calendar days with closed days masked, the published
schedule and school-holiday distance as covariates, and starts every forecast at
park-local today; it changes the training data shape, so it is shadowed first.
See docs/ml/neuralforecast-tft-evaluation.md (PAR-1033 section).
