### Fixed — entity mapping sync no longer aborts on a nameless entity

Since PAR-803 (#465) `normalizeForMatching` stripped ®/™ with `text.replace` before anything else, so an entity a source lists without a name threw and aborted the whole park's `entity-mappings/sync-park-mappings` run every night from 2026-10-14. An absent name now normalises to an empty string, and the matcher never pairs two empty names (slug match, ride signature, entity similarity).
