### Added — the admin ride list carries attractionKind

Each entry in `GET /v1/admin/content/parks/:id/attractions` now has
`attractionKind` (`RIDE`, `TRANSPORT`, `SHOW`, `WALKTHROUGH` or `null`), read
raw from the column so `null` still means "nobody decided" and never `RIDE`.
The bulk `PATCH` on the same path and the options in
`GET /v1/admin/content/fields` already covered the key through the curated
field spec list; `admin-curation.service.spec.ts` tests that path.
