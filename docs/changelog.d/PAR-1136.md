### Fixed — `/weather` without `to` returns the last month, and an empty yearly forecast is no longer cached for a day

`GET …/weather` without `to` added the endpoint's 0 days to `from`, so a bare request returned one
day 30 days back; `to` now defaults to the park's today, as documented. When the forecast cannot be
read, `/predictions/yearly` answered `predictions: []` under its 24-hour cache, and the edge kept the
outage for a day; that answer now carries `isDegraded: true` and is sent `no-store`. Swagger and
docstrings follow the code: the yearly `generatedAt` is the response time, the nowcast answers 404
(not 503), its `observedAt` is the request time and `nextUpdateAt` the next quarter-hour mark,
favorites cache 5 minutes in Redis and send `no-store`, and the seasons route has no day-long cache
([weather](frontend/weather.md), [yearly predictions](frontend/yearly-predictions.md)).
