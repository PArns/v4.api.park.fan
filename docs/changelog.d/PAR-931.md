### Added — the park payload carries `runsOnWeekdays` for rides that skip a weekday

`plan/day` loads last on the park page, so until it arrived a Halloween maze on
a Monday read „not yet today" and then switched to „not on today's programme".
Each ride in `GET /v1/parks/{continent}/{country}/{city}/{park}` now carries the
same `runsOnWeekdays` as `plan/day`, from the same cached pattern, but only when
it leaves a weekday out. A ride that runs daily, or has no pattern, carries
nothing. Measured on 2026-10-19: Movie Park Germany gains the field on 8 of 39
rides, +30 B brotli on 6,628; Europa-Park on none, +0 B. The five-minute poll is
a field list in the frontend and does not carry it.
