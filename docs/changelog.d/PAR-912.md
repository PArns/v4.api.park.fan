### Fixed — accuracy figures no longer score rides that were not running, and q0.8/q0.95 are stored

65–70 % of the hourly compared rows in `prediction_accuracy` had an actual of 0, and with them every CatBoost version read MAE 11–12 min and bias +10 (measured 2026-10-17, six days). One day re-derived against `queue_data` split those zeros into 41.8 % rides not scheduled to run (CLOSED before their first run of the park-local day, REFURBISHMENT), 37.8 % rides that publish no wait at all (OPERATING with 0 and no wait above 0 in seven days), 11.1 % unplanned closures (DOWN, or CLOSED after the ride had run) and 9.2 % real 0-minute waits. `compareWithActuals` now classifies each slot into the new `score_class` column (`scored` / `unplanned_closure` / `ride_not_operating` / `no_wait_signal`); the two "not an error" classes stay COMPLETED — they were checked, so coverage is unchanged — with a NULL actual and NULL errors, and an unknown reading status is no reading rather than a closure. Unplanned closures keep their rule. One predicate, `scoredSlotSql`, decides "forecast error" for the readers that were distorted: the system overall MAE (`/v1/ml/accuracy/system`, dashboard `live`; 10.1 → 6.9 over the same seven days), `byPredictionType.HOURLY`, the feature-error analysis and the daily anomaly detection, which raised `large_error` for closures. The accuracy alert threshold moves 13 → 10 (ladder 10/13/17) with it. The badge, `raw_mae`, drift and the pattern boards already dropped every zero through their `actual ≥ 5` filter and are unchanged. Rows compared before the change carry no class and count only with a positive wait — no backfill; they age out with the 90-day retention. `prediction_accuracy` also gains `predicted_q80` / `predicted_q95` (the model's raw quantiles from predict.py, stripped from every served read), and the dashboard's new `performance.operating` reports MAE, bias and P(actual ≤ q0.5/q0.8/q0.95) per model version. Cache keys: `accuracy:sys:v2:*`, `ml:dashboard:v3`, `accuracy:operating:v1:*`. Three nullable columns on a plain table, no index. docs/ml/accuracy-scoring-rule.md.
