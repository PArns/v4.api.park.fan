### Fixed — name matching keeps a trailing country code

`normalizeForMatching` no longer strips a suffix such as `(DK)` or `(UK)`. At LEGOLAND Billund it names the language of a show, so `V.I.M. Dance Party (DK)` and `(UK)` collapsed to one key, and a second source's data could land on the wrong one. The new rule affects 3 rows in `shows`; no attraction or park name carries a suffix. `slug.util.spec.ts` asserts that the two keys differ.
