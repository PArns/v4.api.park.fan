### Removed — the uncalled `AttractionsService.syncAttractions` write path

`AttractionsService.syncAttractions()` had no caller outside its own spec; the live
attraction catalogue sync is `ChildrenMetadataProcessor`. Its Queue-Times and
Wartezeiten branches (`syncFromQueueTimes`, `syncFromWartezeiten`, `upsertAttraction`)
matched existing rows by `externalId` only and lacked the PAR-161 show-name guard,
so reviving it would have recreated the "-2" duplicates. The method, its
`ThemeParksEntitySync` hooks, the five constructor dependencies only it used and
`attractions-sync-dedup.spec.ts` are gone. No behaviour change.
