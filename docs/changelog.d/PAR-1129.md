### Security — a viewer can no longer start the downtime rebuild, and the admin guard reads the address like the throttler

`POST /v1/admin/rebuild-downtime` carried no `@AdminMinRole`, so any signed-in `viewer` could queue a
reconstruction up to 400 days back; it now needs `editor`, like every other job trigger. A new spec
walks every `POST`/`PATCH`/`PUT`/`DELETE` route of `AdminController` and fails on one without a
minimum role. `clientIp` in the admin guard is now `getRateLimitIp`, so the admin login honours
`CF_ORIGIN_SECRET` and falls back to the socket rather than a caller-written `X-Forwarded-For` hop or
`req.ip`; the bypass key is compared in constant time for every reader
([edge and throttling](deployment/edge-and-throttling.md#which-address-a-request-is),
[admin endpoints](admin/endpoints.md)).
