### Fixed — The admin's queue screen shows the Search Console import and why any counted queue failed

`queue-status` counted eleven queues but not `search-console`, so a click on
"import now" left no trace anywhere until the run ended (four clicks on 28 and
29 October, during the backfill of image, news and Discover). It now counts
`search-console` and the other queues the admin starts by hand (`downtime`,
`pcn-shadow`, `park-day-operation`), fifteen in all. `queue-failures` accepted
only eight of the counted queues, so the screen's "why" answered
`Unknown queue "ml-training"` (and the same for `holidays` and
`park-enrichment`); every counted queue's failures can now be read. See the
[admin endpoints](admin/endpoints.md).
