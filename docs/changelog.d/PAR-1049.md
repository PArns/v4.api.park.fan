### Fixed — an unpublished school break is unknown, not "no school holiday"

Past a region's last stored school-holiday row, every consumer used to read "no
school holiday": Spain's school rows end 2026-09-11, Italy's 2026-09-15,
Hungary's 2026-08-31, Mexico's 2026-07-15, Ireland's 2026-04-12, and Sweden and
Singapore have none — while public holidays reach 2028. OpenHolidays has no
ES/IT/HU school holidays for the next school year either, so nothing is
projected; the coverage is now derived per (country, region, type) from the
stored rows and the day past it reads as unknown.

- **CatBoost** (training and inference, one function): the four school columns
  are NaN past the coverage. Default `nan_mode = Min` keeps the current model's
  predictions unchanged until the next training.
- **TFT**: new `school_holiday_known` covariate, in `FUTR_EXOG_GRID` only
  (`NF_CALENDAR_GRID`); the default model's inputs are byte-identical.
- **Chronos-2 shadow**: `holidays_through` per type — Spain no longer reads as
  covered to 2028.
- **Calendar, `/best-days`, `/plan/day`**: additive `schoolVacationUnknown: true`
  on such days; the plan's climatology tier does not match them as "regular".
- **Holiday sync** logs the countries whose school data ends within 90 days.

See [School-holiday coverage](../architecture/school-holiday-coverage.md).
