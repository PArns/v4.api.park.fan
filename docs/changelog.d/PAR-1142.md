### Added — ml-bench reports slot MAE by target weekday

The report writes `mae_by_weekday.csv` beside `mae_by_season.csv`: slot MAE per
model for leads 0, 1, 3, 7, 14 and 30, split by the target day's weekday. Until
now no output table had a weekday column, so a run whose origins all fell on one
weekday could only be caught by the runner's census, not seen in the results
([harness](ml/ml-bench/harness.md)). The baseline tables already published
predate it; rerunning them is a separate step.
