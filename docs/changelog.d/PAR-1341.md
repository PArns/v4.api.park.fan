### Changed — H5 and fresh hourly runs are on by default; lead snapshots reach 180 days; dead deviation flags are gone

Five smaller changes from the ML review of 2026-11-14.

- **Defaults in `docker-compose.production.yml`.** `PLAN_DAY_H5_COMPOSER=true` with
  `PLAN_DAY_H5_MAX_LEAD_DAYS=21`: `/plan/day` composes days 2–21 from the H5 profile in 15-minute
  slots, the leads the model comparison had decided (days 2–5 −1.46 min against the old composer,
  CI −2.04 to −0.91; days 6–21 −1.79 min). `GENERATE_HOURLY_FRESH=true`: every 15-minute run asks
  CatBoost (PAR-1330); a run that took 10 minutes or more makes the next one read the cache, so the
  job cannot fall behind its cadence, and the run's log line now says how long it took and which
  path it used. `CALENDAR_SEASON_FILTER` is passed through, default off. Chronos-2 serving stays
  off: this release refills its truth cache, and its
  [switch-on checklist](ml/forward-archive/chronos-serving.md#switch-on-checklist) wants a warm
  one.
- **Lead snapshots at 120 and 180 days** (`LEAD_BUCKETS`), so the daily level's long range is
  measured at all; first figures about 120 and 180 days after the deploy
  ([long-range forecasting](ml/long-range-forecasting.md)).
- **`PredictionDeviationService` is removed.** It ran two queries on every live OPERATING reading
  with a wait and wrote a Redis flag (`prediction:deviation:*`) that no API route and neither
  frontend read. `deviationDetected` and `deviationInfo` stay on the prediction DTO; nothing ever
  set them.
- **D6 in the forward archive** rated a day's value without heartbeat rows against a baseline
  that counts them. Both sides read the calendar's statistic now
  ([scoring](ml/forward-archive/scoring.md)). Admin scores only.
- **Two CatBoost weather features can be aligned at serving**, each behind its own switch in
  `ml-service`, default off. `FAR_RAIN_FROM_WEATHER_CODE`: past the weather forecast the
  climatological precipitation is a monthly mean and never 0, so every row beyond ~16 days — all
  of days 61–365 — read `is_raining = 1`; on, such a row takes the month's most frequent weather
  code. `TEMP_DEVIATION_ROW_BASELINE`: training subtracts the mean over a park-month's rows
  (operating hours), serving subtracted the all-day climatological mean, so a served row read
  4–5 °C warmer than normal; on, serving subtracts the mean of the climatological curve over the
  rows it is asked about. Neither is measured: switch one at a time and read the forward archive.
