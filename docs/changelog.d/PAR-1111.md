### Added — the nightly backup also saves the PCN models

`parkfan-backup.sh` copied the CatBoost and nf-service models to the NAS but
not `/data/parkfan/pcn-models`, so a lost disk meant retraining every park
before the intraday nowcast came back. The PCN directory is now archived the
same way as nf-service's, the last three archives kept, through one shared
function ([backups](deployment/backup.md)). A rehearsed restore is still open.
