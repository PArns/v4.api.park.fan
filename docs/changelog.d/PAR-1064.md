### Added — ml-bench: TimesFM 2.5 plug-ins, and TimesFM 3.0 marked benchmark-only

`timesfm25` (compressed context, also the daily level behind `timesfm25_x_h5`) and
`timesfm25_grid` run `google/timesfm-2.5-200m-pytorch` (Apache-2.0, revision pinned),
which ships in the `timesfm==3.0.2` wheel already used for TimesFM 3.0. Covariates go
through the package's in-context regression (`forecast_with_covariates`, CPU jax), one
fit per park; there is no q95 head. Re-reading the TimesFM 3.0 licence corrected the
docs: it grants non-commercial **and non-production** use and excludes use in
interactions with end users or production systems, so `timesfm3` can never be served
on park.fan — it was described as an owner decision before. Not run on the GPU yet.
