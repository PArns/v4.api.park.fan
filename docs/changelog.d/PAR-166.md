### Changed — the `test-exclude` override is gone, coverage still instruments 316 files

`pnpm-workspace.yaml` forced `test-exclude` to 8.x because 6.x called
`promisify(require('glob'))`, which throws from glob 9 on. The only consumer
today is `babel-plugin-istanbul@8.0.0`, which asks for `^7.0.1`, and 7.0.2
destructures `{ glob }` instead. Without the override it resolves to
`test-exclude@7.0.2` on `glob@13.0.6`, the same glob as before. `pnpm test:cov`
prints no `Failed to collect coverage` line and lists 316 instrumented files,
as it did with the override (237 suites, 3613 tests passed both times). The
comments on the `glob` and `minimatch` lines now name `test-exclude@7.0.2`
instead of 8.
