### Added — the API states its terms: free for non-commercial use, forecasts never commercial

The OpenAPI description carries `info.termsOfService` and `info.license`, both
pointing at `https://park.fan/en/impressum#data-use` (`DATA_TERMS_URL` in
`src/common/swagger/swagger-config.ts`), and its description says the terms in
one sentence. The README served at api.park.fan/ replaces "License: UNLICENSED,
contact the maintainer" with the terms: free for non-commercial use with a
credit; park.fan's forecasts never in a commercial product, and no commercial
licences; live wait times, opening hours and weather under their sources'
terms. Until now the API published no terms, so a commercial app had nothing to
read but an invitation to get in touch. The rate limit is unchanged: it is a
per-address circuit breaker, and an app that caches a few parks once a day stays
far below it. The frontend side, with the terms text itself, is PArns/park.fan#1201.
