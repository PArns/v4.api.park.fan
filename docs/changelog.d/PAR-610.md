### Added — the admin ride list carries virtual line, single rider and indoor/outdoor

`GET /v1/admin/content/parks/:id/attractions` returned only the fast-pass
columns and the attraction type. Each entry now also has `hasVirtualLine`,
`hasSingleRider` and `indoorOutdoor`, read raw from the columns so `null` still
means "nobody has checked". The bulk `PATCH` on the same path already accepted
these keys and `curatedAttractionType` through `ATTRACTION_CURATED_KEYS`; a spec
now covers it.
