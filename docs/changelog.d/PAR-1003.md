### Fixed — /stats reads one set of numbers whatever minSampleDays asks for

`minSampleDays` was still part of the `/stats` cache key, although it only
decides `meta.displayable`. Two requests with different values therefore read
payloads computed on separate 24-hour cycles, the same split PAR-983 closed for
`topN`. The key is now park, years and `minAttractionDays`; `displayable` is
derived from `totalSampleDays` on every read.
