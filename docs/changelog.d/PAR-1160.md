### Added — Google Search Console in the admin: queries, pages and clicks from Google, next to our own traffic

New module `src/search-console/`. A Google service account (`GSC_SERVICE_ACCOUNT_JSON`, raw or base64,
and `GSC_SITE_URL`, e.g. `sc-domain:park.fan`) reads Search Console's `searchAnalytics.query`; without
both the module is off and `status.configured` is false. A small client over `fetch` and Node's
`crypto` (the service account's RS256 JWT, an access token kept until a minute before it expires)
replaces `googleapis` (about 245 MB unpacked) and `google-auth-library`: no new dependency. The
Bull queue `search-console` imports nightly at 09:20 UTC and on demand: the last `GSC_IMPORT_DAYS`
days (default 3, Google finalises late) again and every day of the last 16 months never fetched, so the
first run is the backfill. Per day, rows by page, query, country and device, and rows without the query
that carry the property's own totals (Google leaves anonymised queries out of the first kind).
`search_console_rows` is a hypertable (30-day chunks, compressed after 35 days, one segment per batch,
chunks dropped past 500 days by the nightly job under a 5 s `lock_timeout`). A day imported again is a
new batch in `search_console_batches` and the reports read only the newest batch of each day, so a
re-import does no UPDATE or DELETE; a day that did not change writes nothing. Page URLs become the
site statistic's paths (origin, query and trailing slash dropped, lower case; `www` and `http` forms
merged; other subdomains skipped) so they join `site_pageviews`.

Admin endpoints under `/v1/admin/search-console`: `GET status`, `POST import` (editor, audited,
`202 { queued: true }`), `GET queries`, `GET pages` (with the site's own visits, bounce rate and visit
length from the `search` channel per path) and `GET series` (day, week, month), with the site
statistic's `days`/`from`/`to`/`locale` window, a change against the window before, and `ctr` and
`position` computed on read (`position` is null without impressions). The MCP tools `gsc_status`,
`gsc_queries`, `gsc_pages` and `gsc_series` return queries, paths and Google's error text under
`visitorData`. New variables `GSC_SERVICE_ACCOUNT_JSON`, `GSC_SITE_URL`, `GSC_IMPORT_DAYS`. Setup:
[Search Console setup](admin/search-console-setup.md); the contract:
[Search Console](frontend/search-console.md).
