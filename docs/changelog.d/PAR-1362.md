### Added — five more topics in Parky's knowledge base, and a seed that adds topics the base never held

Parky's knowledge base starts with five more topics beside `forecasts`, each written from a source
park.fan already has: `crowd_scale` (the ladder, live against a ride's normal and days against a
typical day, normal, busy and record), `data_sources` (the wait-time sources and their cadence,
holidays, weather, opening hours, the three cases where a field stays empty), `ride_status` (the
statuses, a ride opening after the gates, how sure a reopening is), `best_times` (optimal, good, the
live slot, the rope-drop rule) and `privacy` (what a chat stores and for how long, what goes to
Anthropic, location, feedback, the statistic, as the privacy page says).

`AssistantKnowledgeService.seed` used to fill only an empty table, so a seed file added after the
first boot never reached the base. It now adds every seed topic the table has never held: one that
is there is never overwritten, and one whose delete is in the audit log is never added back. Two
eval cases (`privacy-what-stored-de`, `crowd-scale-why-very-high-en`); the eval has 101.
Background: [Parky's knowledge base](frontend/assistant.md#parkys-knowledge-base).
