### Fixed — the calendar spec no longer turns red once its dates are in the past

`calendar.service.spec.ts` mocked `calculateCrowdLevelForDate` as `null`, a value
the real method never returns (a day without data answers `hasData: false`).
`buildCalendarDay` only reads that result for a strictly past day, so the mock
went unnoticed until 2026-10-02 UTC, when 1 October stopped being today and
"builds October 2026 as 31 distinct days" threw on `crowdData.hasData`. The mock
now returns the no-data shape. No change to calendar behaviour.
