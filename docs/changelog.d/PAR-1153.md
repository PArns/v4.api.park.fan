### Security — no full address in any log line

The privacy policy says the server logs no IP addresses, but `LoggingInterceptor` wrote `request.ip`
into the line of every error, slow request and admin request, and the admin login wrote the caller's
address when Turnstile refused it. Now an admin request line carries at most a /24 (IPv4) or /48
(IPv6) from `truncateIp`, which moved from the auth service to `src/common/utils/request.util.ts`;
every other route's line, and the Turnstile refusal, name no address. `redactUrl` also hides the `ip`
query parameter of the location and favourites routes, and the slow-query file and the error line of a
failed statement cut any address among the bound parameters to its network. `admin_audit_log.actor_ip`
stays whole: it is the accounts' record, not a log of visitors. A spec reads every file in `src/` and
fails on a logger call that names an address. See [the rule](rules/no-address-in-logs.md).
