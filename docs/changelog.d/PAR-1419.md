### Changed — the admin and parks controllers lose their copies

`admin.controller.ts` held 49 routes on 2365 lines with 32 constructor
arguments. The 17 job triggers, `rebuild-downtime`, `flush-cache` and
`cache/reset` are now `AdminJobsController`, one `@JobTrigger` decorator per
route instead of five and one `enqueue` helper instead of seventeen copies of
`queue.add` plus the answer. The duplicate-park merge moved into
`ParkDuplicateMergeService` unchanged, its spec with it.
`validate-and-repair-parks` lost the half that never ran: it built two empty
lists of mismatch fixes on every call and repaired nothing with them; the
missing ids it does add are now `ParkRepairService.addMissingIds`.
`AdminController` is 968 lines. Every URL, role and answer stays as it was, and
the MCP tools call the same handlers on their new class.

Every audited admin controller now carries `@AdminApi(path)` instead of the
same five class decorators, so a controller split off another cannot keep the
prefix and lose the guard. The role test walks `AdminJobsController` too.

In `parks.controller.ts` (2338 → 2003 lines) the park lookup and its 404 were
written out thirteen times, the four path parameters' Swagger blocks thirteen
times, and eight `await import(...)` loaded modules that load fine statically.
They are a helper, `@ApiParkPath()` and plain imports now; `plan/day` uses
`isRealIsoDate` and the two lists `PaginationDto` instead of rebuilding them.
The Swagger example for Phantasialand's city was `bruhl`, which answers 404;
it is `bruehl`.

Visible to a caller, all on admin routes: an integer query parameter that is
not an integer (`?days=abc`) answers 400 through `@QueryInt` where it fell back
to the default; `backfill-park-day-operation` refuses a day the calendar does
not have (`2026-02-31`); `model-comparison/day` takes ids only in the canonical
lowercase form `isCanonicalUuid` accepts; and the region list of the two
forecast boards and the MCP `model_comparison` tool is one constant,
`SCORE_REGIONS`.
