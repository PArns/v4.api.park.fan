### Added — one admin page that says what is up for decision and whether every ML component ran

`GET /v1/admin/ml-overview` (admin auth, cached 5 min) answers three questions:
the open switch decisions, the model comparison's summary, and per component
(PCN, TFT, CatBoost, Chronos-2, H5 profiles, Shape, forward archive, scoring)
what it delivers, when it last ran, when it should run and `ok` / `late` /
`failed` / `warming` / `unknown`. The decisions live in
`src/ml/data/ml-decisions.json` (six seeded) and rest on cells of the model
comparison matrix: `ready` when every cell is better offline and live,
`waiting_live` while the 14-day / 10-park gate is not met, the least-measured
cell as progress and today + the missing days as the earliest date. Every
status read is an index lookup under a 10 s statement limit — 0.6 to 46 ms on
production, TFT 20 ms warm through the primary key because `tft_forecasts` has
no time index (a `max(created_at)` scans 3.4 GB in 0.7 s). The forward archive
now records each run's Chronos call summary in Redis so the page can say the
shadow is still loading history. See docs/ml/ml-overview.md.
