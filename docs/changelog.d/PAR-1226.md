### Added — the CPU temperature carries the chip's own limits

`/v1/admin/system-health` already reported the CPU package temperature, but the admin judged it
against a fixed 70/85 °C. On Intel the package follows the hottest core, so one core at 85 °C under
load turned the server red although the production CPU (Core Ultra 9 275HX) throttles only at
105 °C. The API now reads the package sensor's `temp*_crit` (TjMax) and sends
`host.cpu.temperatureLimits`: amber from TjMax − 15, red from TjMax − 5, so 90 and 100 °C on that
host. A sensor without a crit is judged under an assumed TjMax of 100 °C. On a host with two sockets
the hotter package counts, and every hwmon sensor carries the driver's `critC` where it has one.
Details in [CPU temperature](frontend/cpu-temperature.md).
