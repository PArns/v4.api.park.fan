### Changed — NestJS 12, typeorm 1, Node 26 and the other skipped majors

NestJS 11 → 12, typeorm 0.3 → 1.1, ioredis 5 → 6, cron-parser 4 → 5 and
dotenv 17 → 18, on Node 26 (CI, Docker and `engines`). Nest 12 ships ESM, which
Jest loads through native `require(esm)`; that needs Node 24.9+ and
`--experimental-vm-modules`, now set in every `test*` script.

Behaviour is held where the new defaults would have changed it: typeorm keeps
ignoring `null`/`undefined` in find `where` (`invalidWhereValuesBehavior`),
the two `@Check` constraints keep their 0.3 hash names, and ioredis stays on
RESP2 (`protocol: 2`). A `synchronize` dry-run against production emits the
same three statements under 0.3 and 1.1 — nothing new happens to the schema on
deploy. TypeScript 7 is not taken: ts-jest, ts-node and the Nest swagger plugin
still need the compiler API it no longer exports.
