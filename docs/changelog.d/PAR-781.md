### Documented — ConflictResolverService gets a spec

`conflict-resolver.service.ts` decides which wait time a ride shows when
ThemeParks.wiki, Queue-Times and Wartezeiten.app disagree. It had no spec and
4.22 % line coverage. `conflict-resolver.service.spec.ts` adds 41 cases through
`aggregateParkData`: single source, majority of three, median of three, average
of two, the 13-minute walk-on, name matching, the CLOSED/DOWN to OPERATING
override with `rawStatus`, and the operating-hours and discrepancy warnings.
Line coverage of the file is now 88.02 %. No service code changed.
