### Changed — conflict resolver, Open-Meteo client and file logger carry no `any`

`ConflictResolverService.mergeEntities` takes and returns typed entities
(`MergedEntity` now extends `EntityLiveData`), and the Queue-Times and Wartezeiten
fields are written by name instead of through a string key. The Open-Meteo client
types its request config as `AxiosRequestConfig` and reads `code` and `message`
off caught errors through narrowing helpers. The file loggers take `error: unknown`
and `Record<string, unknown>`. No behaviour change.
