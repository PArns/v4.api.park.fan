### Fixed — `POST /v1/admin/flush-cache` no longer deletes the Bull queues

The pattern list carried `parkfan:*` for the latest-queue snapshot and the
attraction timezone cache. `parkfan` is also Bull's default prefix, so one call
deleted every queue's job hashes and its `wait`, `delayed` and `repeat` keys,
and no cron ran again until the API restarted. The list now names the two
cache families (`parkfan:queue:latest:*`, `parkfan:attraction:tz:*`), and
`flush-cache-patterns.spec.ts` fails if any pattern matches
`<BULL_PREFIX>:<queue>:*` for every queue registered in
`src/queues/queue-registrations.ts` or named in a `@Processor`/`@InjectQueue`.
