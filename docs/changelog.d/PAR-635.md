### Removed — the uncalled `syncShows` / `syncRestaurants` paths and `ThemeParksEntitySync`

`ShowsService.syncShows()` and `RestaurantsService.syncRestaurants()` had no caller
outside their own specs (and one unused e2e mock); shows and restaurants are synced
by `ChildrenMetadataProcessor`. With `syncAttractions` gone since PAR-327, the shared
`ThemeParksEntitySync` base class had no user left. Both methods, their hooks, the
base class and its spec, the three constructor dependencies only the sync used
(`ThemeParksClient`, `ThemeParksMapper`, `ParksService`) and the matching
`ThemeParksModule` / `ParksModule` imports in `ShowsModule` and `RestaurantsModule`
are gone. No behaviour change.
