### Changed — the API's heap is set in one place

The API container carried two heap limits: `--max-old-space-size=6144` in the
Dockerfile's `CMD` and `NODE_OPTIONS=--max-old-space-size=4096` in
`docker-compose.production.yml`. Node lets the command-line flag win, so the
4096 did nothing. The flag is gone from the `CMD`; the compose file now sets
6144, the value production has run with, so the deploy moves no limit. The
container limits themselves wait on a night of `memory.peak` readings
([container memory limits](deployment/container-memory-limits.md)).
