### Added — accounts and key requests can be deleted for good

`DELETE /v1/admin/auth/users/:id` (owner only) removes an account with its sessions, API tokens,
and for a developer its API keys with their counters and every key request; the key stops working
at once. Nobody deletes their own account or the last active owner. A key request can now be
deleted in any state.

Demoting or deactivating an owner answered 500: the check for another owner locked a `COUNT`, which
Postgres refuses. It now locks the rows, and the deletion uses the same check.
