### Security — the consent page says when an OAuth request was started from another country or browser

`/v1/oauth/authorize` parks the GeoIP country and the browser family of the browser that started the
request next to it, for its ten minutes in Redis; the address and the User-Agent are not kept. A
request without a User-Agent, which no browser sends, counts as another browser.
`GET /v1/admin/oauth/requests/:id` answers them as `startedFrom`, and as `viewer` the same two facts of
the admin reading the page: the country from the admin's address, the browser from the User-Agent the
session signed in with, because the request itself arrives through the admin proxy. The consent page
warns when they differ, which is what a link somebody else started and sent over looks like; the
starter chooses both facts, so the warning is a hint, not a control. The grant's audit row
`auth.oauth.grant` records `startedFrom`. `CF_ORIGIN_SECRET` stays unset in production, which
[edge and throttling](deployment/edge-and-throttling.md) now records: from the internet the API is
reached only through a Cloudflare Tunnel. See [admin MCP](admin/mcp.md).
