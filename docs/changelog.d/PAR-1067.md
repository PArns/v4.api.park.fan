### Added — ml-bench: Granite PatchTST-FM-r2, Granite TTM-r2 and TabPFN-TS plug-ins, and a licence guard

Four new benchmark arms: `patchtst_fm` (zero-shot, no covariate input, a real q95 from its
99-quantile head), `ttm_r2` (zero-shot, no covariates), `ttm_r2_ft` (the covariates as
exogenous channels, fine-tuned every 28 days on truth before the origin) and `tabpfn_ts`
(the daily level only, with known-future covariates, against `driver_level` and `wt_med`).
PatchTST-FM-r2 (Apache-2.0 or OpenMDW-1.0) and TTM-r2 (Apache-2.0) may be served; TabPFN-TS
runs on the TabPFN-3.5 weights, whose licence rules out production use, so it is
benchmark-only. Every foundation plug-in now declares its licence verdict. A
benchmark-only model marked as a serving candidate fails as soon as the class is defined,
and `run-*.json` records both fields. The optional `requirements-par1067.txt` also fixes
`requirements-par1063.txt`, which silently upgraded numpy to 2.x through jax's
`ml_dtypes`. `run.sh` passes `HF_TOKEN` / `TABPFN_TOKEN` through from the caller's
environment. Nothing has been run on the GPU yet; the combined run command is in
`docs/ml/ml-bench.md`.
