### Fixed — the merge's source-id guard reads the coordinates Postgres returns

`canInheritSourceIds` decided on `typeof latitude === "number"`, but `latitude`
and `longitude` are `decimal` columns and TypeORM returns them as strings. Every
row loaded by `park-merge.service.ts` therefore read as "no coordinates", and the
function answered `allowed: true` for every pair whatever the distance — the
Orlando/Tampa protection it exists for never fired. `toCoordinate` now coerces
with `Number` (blank strings stay "no position") and the spec covers the string
form next to the numeric one.
