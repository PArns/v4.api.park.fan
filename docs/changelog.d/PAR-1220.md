### Fixed — TFT forecasts for ten US parks no longer stuck since 2026-10-24; deploys shut down inside the deadline

The nightly TFT run skipped one park chunk every night since 2026-10-24, so
Magic Kingdom, Epic Universe, Hersheypark, Busch Gardens Tampa and six more
parks kept a stale daily forecast. The chunk held ten rides with a single
observed day; such a series has no training window, and a batch drawn only
from them made NeuralForecast raise "No windows available for training". Since
chunk membership became stable (PAR-1054) the same chunk failed every night.
Those series now stay out of the fit only — they still get a forecast, as the
model is global. The calendar-grid shadow had the same failure for a Chinese
chunk since 2026-10-31.

Every deploy since 2026-10-30 also ran into the 20 s shutdown deadline
(exit 143), because Bull waited for the ~200 s `live-cache-warmup` job. The
warmup now stops between batches once the shutdown has begun.
