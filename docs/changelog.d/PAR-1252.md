### Fixed — The queue screen and the MCP count every queue; `system_health` fits the answer limit

`queue-status` (and the MCP `queue_status`) counted fifteen hand-picked queues out of more than
forty. When celestrial rebooted on 2026-11-07, `live-cache-warmup` failed and the data-quality card
showed it, but the queue screen and the MCP did not. The counts now cover every queue in
`BULL_QUEUE_REGISTRATIONS`, the list the data-quality monitor already reads, and `queue-failures`
can read the failures of any of them.

The MCP `system_health` answered `section: ml` with about 131k characters. The MCP cuts every answer
at 100k, so the end of the ML half never arrived. The two PCN boards now return their verdict and
count; their per-day rows come back only when you ask with `boardRows`
([MCP](admin/mcp.md)).
