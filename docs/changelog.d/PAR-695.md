### Changed — a silenced cluster carries its rides, and rides with a known season no longer count as silenced

The data-quality page asks of every silenced cluster "season ending, or a
dropped feed?" and could only answer with a link. `findSilencedClusters` now
returns every ride of the cluster with its id (`attractions`), so the admin can
put a season window on all of them in one step, and it skips rides whose
season is known (`curated_is_seasonal`, else `is_seasonal`) and retired rides —
otherwise the answer would leave the card standing.
