### Changed — Parky offers no best visit times for a ride on set times

A ride whose performance schedule covers the park's today
(`today.performances` on Parky's `get_ride`) no longer carries
`bestVisitTimesToday`: the wait forecast's quiet slots said „around 12:45" for
Phantasialand's 4D cinema Die 3 Mausketiere, which starts on the hour. The
system prompt (version 59) has Parky name the next start instead. The site
drops the same slots for such a ride. Contract:
[performance schedules](frontend/performance-schedules.md).
