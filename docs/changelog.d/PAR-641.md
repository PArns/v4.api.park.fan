### Fixed — `backfill-percentiles` fills gaps instead of doubling legacy buckets

`handleBackfillPercentiles` relied on `ON CONFLICT (id, hour) DO NOTHING` to skip existing
buckets. The 305,246 of 792,529 rows (39 %) that still carry a `gen_random_uuid()` id are
invisible to that conflict target, so a 365-day run would have inserted 292,656 second rows
beside them.

The statement now wraps `HOURLY_AGGREGATE_SELECT` and adds `WHERE NOT EXISTS` on the natural
key (`"attractionId"::text`, `hour`), which `IDX_484fd793abf13a7d66f8f61b8f` serves.
`handleCalculatePercentiles` keeps `DO UPDATE`. No schema change, and the existing duplicate
buckets are untouched.
