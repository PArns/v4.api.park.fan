### Fixed — ml-bench: the image has a C compiler for Triton

The first GPU probe of `kumo_level` (PAR-1405) failed with "Failed to find C compiler": Triton
builds its CUDA launcher at the first kernel call, and the slim image had no compiler. The CPU smoke
never got that far. The bench `Dockerfile` now installs `gcc` and `libc6-dev`.

The tabular arms predict in chunks of 4,000 query rows instead of 20,000
(`MLBENCH_TFM_QUERY_CHUNK`): the first full run on the RTX 5080 ran Inpriora out of the bench's
9.3 GB GPU cap at its April origins. Query rows do not see each other, so the levels are the same.
