### Fixed — duplicate list no longer says "same name" for two different names

`findDuplicatePairs` chose the `reason` text by the source of the two ids, so a pair of
different names from one source (Cedar Point `Midnight` / `The Conjuring: Beyond Fear`,
Parque Warner `Arkham` / `Shadows of Arkham`) was described as "same name" and showed
only one of the names. The text now follows the names: different names list both, equal
names from one source keep the old wording. The `safe` verdict is unchanged.
