### Removed — the show season guard in `/plan/day`

`PlanDayService.showOutOfSeasonOn` and its call in `buildShows` are gone. The guard
dropped a projected show when `season_months` excluded the planned month, but
1,414 live shows carry `is_seasonal` and none carries `season_months`, so it never
fired. A show's season now comes from the pattern window alone: no sighting in 28
days drops the projection. No response changes.
