### Fixed — the drivers shadow's `sched_asof` is no longer 1 on every day

`nf-service` `fetch_schedule` compared a window's last write with
`GREATEST(day start, now())`. For a past day that is `now()`, for a future one the day start, and
`updatedAt` is never later than either, so `sched_asof` was 1 wherever an OPERATING row existed:
the history read opening hours written on the day itself or afterwards as published ahead, and
`sched_known` said no more than "a window exists". The bound is `LEAST(…)` now, the rule
[TFT grid shadows](ml/tft-grid-shadows.md) describes. Shadow only (`tft_forecasts_shadow_drivers`,
archive model `tft_grid_drivers`); its archive rows before and after the deploy come from two
different models, so the 14-day count for the 2026-12-24 decision starts again. The test pins the
SQL text; the suite runs no Postgres.
