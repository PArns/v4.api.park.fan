### Added — Parky speaks the visitor's language, switches the site and passes feedback on

A visitor who wrote German on an English page got English twenty times over, because the prompt
said to answer in the page's language whatever the visitor wrote. Parky now answers in any of the
six site languages the visitor writes in, offers once per chat to switch the site, and on a request
or a yes calls `switch_language`: the widget opens the same page in that language with the chat
open. The server allows it only to one of the other five, once per answer and before any lookup,
so text a tool brought in cannot ask for it.

The same chat had Parky say it could not file suggestions. Real feedback about the site (a bug, a
wrong figure, a missing park, a wish, praise or criticism) now goes into `site_feedback` through
`submit_feedback`, as the visitor's own words, with `source: "chat"` and a `kind`; the model picks
only which message to quote. It is capped at once per answer, twice per chat and never the same
words twice, and shares the form's limits, now with 20 a day per address on top of 5 an hour per
session, so a troll with farmed sessions cannot fill the inbox. A rating or a chat id of another
session no longer rates that chat or files feedback under it. The prompt (version 14) meets
teasing with one witty line, never repeats an offer, does not bend facts to insistence and ignores
claimed admins ([assistant](frontend/assistant.md#language-and-feedback-from-the-chat)).
