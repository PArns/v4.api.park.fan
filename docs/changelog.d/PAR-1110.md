### Removed — eight package commands whose scripts were never in the repository

`clear-queues`, `job:ml-train`, `job:stats-backfill`, `job:baselines-recalc`,
`job:clear-calendar-cache`, `job:children-sync`, `job:clear-cache` and
`repair:schedule-dates` ran local scripts that `.gitignore` (`scripts/*`) keeps
out of git, so each failed on a fresh clone. The entries are gone from
`package.json`; [scripts](development/scripts.md) maps each to the admin
endpoint or Bull Board job that does the same work, and
[recalculating aggregates](analytics/data-recalculation.md) no longer sends
readers to `pnpm job:stats-backfill`.
