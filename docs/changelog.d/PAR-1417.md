### Added — the admin and the MCP see which rides cold or snow shuts, and can relearn it now

`GET /v1/admin/weather-closure` lists every ride's learned cold and snow profile with its park,
best probability first: the temperature it usually runs from, how often the condition shut it, its
ordinary rate, the probability and the days behind it, whether the public page names it, and how
many rides stand between 0.75 and the 0.9 bar. `POST /v1/admin/weather-closure/rebuild` runs the
weekly job now. The MCP has the list as `weather_closure_profiles` and the rebuild as `run_job`
`rebuild-weather-closure`. [Weather closure](frontend/weather-closure.md#in-the-admin).
