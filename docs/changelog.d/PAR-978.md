### Added — `stats/hourly` takes an explicit `from`/`to` window

`GET /v1/parks/:continent/:country/:city/:parkSlug/stats/hourly` only knew "the last `years` years" and ignored `from`/`to`: on 2026-10-22 Phantasialand answered `dataFrom 2025-10-21`, `dataTo 2026-10-21` with and without them, so a post could not set the hourly profile before the new Quick Pass beside the one after it (PAR-778). Both park-local days, inclusive, now replace the `years` window and come back in `meta.dataFrom`/`meta.dataTo`; `meta.windowYears` reports the span read. `parseHourlyProfileRange` in `parks.controller.ts` answers 400 for only one of the two, an impossible date (`isRealIsoDate`), `from` after `to`, or a span over 1830 days. A window with too few measured days answers `displayable: false`. The window is appended to the `park:hourly-profile` cache key only when given, so a request without it keeps its key and its response.
