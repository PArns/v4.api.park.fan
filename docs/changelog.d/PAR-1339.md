### Added — read-only measurement scripts for three open model questions

`scripts/ml-review/` holds what has to be measured on production data before anything is built,
to be run the next time database access is at hand: `hurdle-replay.sql` (what serving 0 would buy
on rides that rarely have a queue, PAR-1335), `park-season-coverage.sql` (how much curated
`park_seasons` history exists and how much busier event days are, PAR-1116) and, in
`nf-service/backtest_headliners.py`, the served sample mean against `TFT-median` from the same fit
(PAR-1334; the holdout is set with `NF_BACKTEST_BASE` / `NF_BACKTEST_END`). The README names, for
each, the result that justifies building. Both SQL files ran against the schema in the e2e
Timescale container ([scripts](development/scripts.md)).
