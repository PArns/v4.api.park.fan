### Fixed — the backup keeps the newest seven CatBoost versions, not the seven copied last

`parkfan-backup.sh` ordered CatBoost versions by mtime, which on the NAS is the
copy time. The prune therefore deleted the earliest-copied version instead of
the oldest one, and the next run copied it back: on 2026-10-22 the 03:00 run
pruned v20261017 while it was still one of the last seven, and a manual run
that evening re-copied it and pruned v20261018. Both lists now sort by the
version name, which is chronological (`vYYYYMMDD_HHMM`).
